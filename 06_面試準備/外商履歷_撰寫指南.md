# 📄 外商履歷：撰寫指南 (Resume Guide)

> **學習目標**
> 1.  掌握 **"6-Second Scan"** 原則 (Recruiter 只看前 6 秒)。
> 2.  學會 **XYZ 公式** (Google 推薦的寫作法)。
> 3.  建立 Firmware 專屬的 **ATS 關鍵字庫**。

---

## 📌 Context: 履歷是用來「被篩選」的

你的履歷只有兩個目的：
1.  **通過機器 (ATS)**: 關鍵字與格式正確。
2.  **通過人類 (Recruiter)**: 在 6 秒內證明你是此職位的強烈候選人。

---

## 🧠 Mental Model (核心觀念)

### 1. 黃金三分之一 ( The Hook)
履歷表的 **上 1/3** 決定了你會被丟進垃圾桶還是繼續被閱讀。
-   **Header**: 名字、聯絡資訊、GitHub/LinkedIn 連結。
-   **Summary (Optional)**: 如果你很資深，用 2 句話總結你的賣點。
-   **Skills**: 把最重要的技能 (Languages, Protocols) 放這裡，讓 Recruiter 一眼看到關鍵字。

### 2. The Scanner Mindset
Recruiter 不是在讀書，是在 **「掃描」**。
-   不要寫一大段文字 (Paragraphs)。
-   使用 Bullet Points。
-   重點關鍵字加粗 (Bold)。

---

## 🔷 Logic I: 寫作公式 (The XYZ Formula)

這是 Google HR 推薦的寫法：
> **"Accomplished [X] as measured by [Y], by doing [Z]."**
> (完成了 X，成效是 Y，透過做 Z)

### ❌ 錯誤示範 (Weak)
*   Responsible for BMC firmware development. (只有 Z，沒 X 和 Y)
*   Fixed bugs in I2C driver. (太模糊)

### ✅ 正確示範 (Strong)
*   **Reduced system boot time by 30% (X)** (from 90s to 60s) **(Y)** by **optimizing U-Boot initialization sequence and removing unused systemd services (Z)**.
*   **Architected a reusable sensor driver framework (X)** that **shortened new platform bring-up time by 2 weeks (Y)** using **Modern C++ design patterns (Z)**.

---

## 🔷 Logic II: 關鍵字優化 (ATS Keywords)

在 BMC / Firmware 領域，請確保你的履歷包含以下關鍵字 (如果真的會的話)：

### 1. 核心技能 (Must Have)
-   **C / C++**: 必備語言。
-   **Embedded Linux / Kernel**: 證明你懂 OS。
-   **OpenBMC / Yocto / Bitbake**: 業界標準。
-   **I2C / SPI / UART / PCIe**: 通訊協定。
-   **GDB / JTAG**: 除錯工具。

### 2. 領域知識 (Domain Knowledge)
-   **IPMI / Redfish**: 管理協定。
-   **PLDM / MCTP**: 現代伺服器通訊標準 (加分!)。
-   **Secure Boot / RoT (Root of Trust)**: 資安熱點。
-   **Thermal Management / PID Control**: 散熱控制。

### 3. 強力動詞 (Action Verbs)
開頭不要用 "Worked on" 或 "Helped"，改用：
-   **Architected** (架構了)
-   **Engineered** (工程化了)
-   **Optimized** (優化了)
-   **Debugged** (除錯了)
-   **Spearheaded** (帶領了)
-   **Automated** (自動化了)
