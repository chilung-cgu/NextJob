# 🔢 位元運算 (Bitwise Operations)

> **學習目標**
> 1.  建立 **Masking (遮罩)** 的直覺 (AND=Filter, OR=Set, XOR=Toggle)。
> 2.  熟練標準巨集操作 (`SET_BIT`, `CLEAR_BIT`)。
> 3.  掌握硬體暫存器操作實務 (**Read-Modify-Write** 陷阱)。
> 4.  能手寫經典演算法 (`popcount`, `reverse_bits`, `swap`).

---

## 📌 Context: 為什麼韌體工程師必須精通位元運算？

因為 CPU 看到的世界就是 0 和 1。
-   **硬體控制**: 設定暫存器的特定 bit 來開關 LED、設定 Baud rate。
-   **節省空間**: 用一個 `int` (32 bits) 就可以存 32 個開關狀態 (Flags)。
-   **極致效能**: 位元運算比乘除法快得多 ( `x * 8` → `x << 3` )。

## 🧠 Mental Model (核心觀念圖解)

### 1. 遮罩 (Masking)

把位元運算想像成「濾鏡」。

-   **AND (`&`)**: 濾網。只保留我想要的 bits，其他過濾掉 (變 0)。
    ```text
    Data: 1 1 0 1 1 0 1 0
    Mask: 0 0 0 0 1 1 1 1  (我想看低 4 位)
    ---------------------
    Rslt: 0 0 0 0 1 0 1 0  (高位全部濾掉變 0)
    ```

-   **OR (`|`)**: 塗改液。強制把某些 bits 塗成 1，原本是 1 的保持 1。
    ```text
    Data: 1 1 0 1 0 0 0 0
    Mask: 0 0 0 0 0 0 1 1  (我想把低 2 位設為 1)
    ---------------------
    Rslt: 1 1 0 1 0 0 1 1
    ```

-   **XOR (`^`)**: 反轉開關。遇到 1 就翻轉，遇到 0 不變。
    ```text
    Data: 1 1 0 1 1 0 1 0
    Mask: 1 1 1 1 1 1 1 1  (全部翻轉)
    ---------------------
    Rslt: 0 0 1 0 0 1 0 1  (等於 NOT)
    ```

## 🔷 Logic I: 基礎操作與標準巨集

韌體開發中最常用的四個動作。請務必背下來。

```c
#define SET_BIT(reg, n)    ((reg) |= (1U << (n)))
#define CLEAR_BIT(reg, n)  ((reg) &= ~(1U << (n)))
#define TOGGLE_BIT(reg, n) ((reg) ^= (1U << (n)))
#define CHECK_BIT(reg, n)  ((reg) & (1U << (n)))

// 實際應用 Example (假設是 GPIO 控制)
uint32_t val = readl(GPIO_MODER);
CLEAR_BIT(val, 5);  // 先清除舊狀態
SET_BIT(val, 5);    // 設定新狀態 (雖然這兩行有點多餘)
writel(val, GPIO_MODER);
```

### 陷阱提示：Signed vs Unsigned Shift
-   **永遠使用 `unsigned` 型別** 做位元運算！
-   `>>` 對 Signed int 行為是「Implementation-defined」(通常是算術右移，補符號位)。
-   `>>` 對 Unsigned int 行為是「邏輯右移」(補 0)。

## 🔷 Logic II: 經典位元技巧 (Bit Hacks)

### 1. 判斷 2 的冪次 (Power of 2)
二進位中只有一個 1。
```c
bool isPowerOfTwo(uint32_t n) {
    return (n != 0) && ((n & (n - 1)) == 0);
}
// 8 (1000) & 7 (0111) == 0
```

### 2. 計算 1 的個數 (Population Count / Hamming Weight)
```c
int countSetBits(uint32_t n) {
    int count = 0;
    while (n) {
        n &= (n - 1); // 每次消除最低位的 1
        count++;
    }
    return count;
}
// GCC 內建: __builtin_popcount(n)
```

### 3. 不用暫存變數交換兩個數 (XOR Swap)
```c
void swap(int *a, int *b) {
    if (a != b) { // 防止同一位址 XOR 自己變 0
        *a ^= *b;
        *b ^= *a;
        *a ^= *b;
    }
}
```

## 🔷 Logic III: 硬體互動實務

### 1. Read-Modify-Write (RMW)
設定暫存器某個 bit 時，不能直接 `= 0x4`，否則會覆蓋其他 bits。必須先讀出來，修改後再寫回去。
-   **風險**: 在多執行緒或中斷環境下，Read 和 Write 之間可能被插隊，導致資料不一致 (Race Condition)。
-   **解法**: 關中斷 (`local_irq_save`) 或使用原子操作 (Atomic instructions).

### 2. Bit-Banding (ARM Cortex-M 特技)
為了解決 RMW 的原子性問題，ARM 允許你透過存取一個「別名位址 (Alias Region)」，來直接操作某個 bit。寫入該位址就等於對該 bit 做原子寫入。

## 📝 精選面試題 (Interview Questions)

### Q1: `n & (n-1)` 的作用是什麼？
-   **作用**: 清除 `n` 二進位表示中 **最低位的 1**。
-   **應用**: 
    1.  判斷是否為 2 的冪次。
    2.  快速計算 Hamming Weight (迴圈次數等於 1 的個數，比逐位檢查快)。

### Q2: 如何實作 `reverse_bits` (反轉位元)？
```c
uint32_t reverse_bits(uint32_t n) {
    n = ((n & 0xAAAAAAAA) >> 1) | ((n & 0x55555555) << 1); // 交換相鄰 1 bit
    n = ((n & 0xCCCCCCCC) >> 2) | ((n & 0x33333333) << 2); // 交換相鄰 2 bits
    n = ((n & 0xF0F0F0F0) >> 4) | ((n & 0x0F0F0F0F) << 4); // 交換相鄰 4 bits
    n = ((n & 0xFF00FF00) >> 8) | ((n & 0x00FF00FF) << 8); // ...
    return (n >> 16) | (n << 16);
}
// 思路: 分治法 (Divide and Conquer)。先換相鄰，再換區塊。
```

### Q3: `~0` 等於多少？`~0U` 呢？
-   `~0` (Signed int): 所有 bits 都是 1，在二補數系統中代表 `-1`。
-   `~0U` (Unsigned int): 所有 bits 都是 1，代表 `UINT_MAX` (2^32 - 1)。
-   **應用**: 常用來產生全 1 遮罩。

### Q4: 如何不用運算子判斷 Endianness？
不能用位元運算 (shift/and/or)，因為這些運算在邏輯層被定義為一致的。必須用 **記憶體存取 (Pointer/Union)**。
```c
int x = 1;
char *c = (char*)&x;
if (*c) printf("Little Endian"); // 低位址存低位 byte (0x01)
else    printf("Big Endian");
```

### Q5: 找出陣列中「唯二」只出現一次的數字？(其餘都出現兩次)
1.  全部 XOR 得到 `A^B`。
2.  取出 `A^B` 最低位的 1 (`mask = res & -res`)。這一位元標示了 A 和 B 的差異。
3.  用這個 mask 把陣列分成兩組：一組該 bit 為 1，一組為 0。A 和 B 會被分到不同組。
4.  對兩組分別做 XOR，即可得到 A 和 B。
